## Verification and delivery

This is a Next.js / TypeScript project. Use npm ci, npm run lint, npm test, npm run build, and npm run typecheck. Run npm run test:preview against a local running server. Execute checks through brain session run so the session records them. Previous Go commands came from generated boilerplate and do not apply.

Follow GitHub #27 as the review-build contract and .plan/ROADMAP.md for milestone order. Browser review covers desktop/mobile, mint light/dark, keyboard navigation, FAQ behavior, link destinations, and accessibility. Document findings in docs/verification.md and durable architecture in .brain/context/architecture.md.

Owner approval is required for public deployment. vercel.json disables Git-triggered deployments. Database workflow work requires funding and approved data governance. No payment or message is sent as a test. Finish with brain session finish after durable notes and checks are recorded.
